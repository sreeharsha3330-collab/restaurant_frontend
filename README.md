# Saffron Table — Restaurant Frontend

A responsive restaurant landing page built with HTML, CSS and vanilla JavaScript.

## Features
- Responsive restaurant homepage and navigation
- Hero section, restaurant highlights and about section
- Menu cards with category filters (Starters, Main Course, Desserts and Drinks)
- Sample menu prices displayed in Indian rupees
- Contact form with client-side confirmation message
- Mobile navigation menu

## Project files
- `index.html` — page structure and content
- `style.css` — layout, colours, typography and responsive styles
- `script.js` — menu rendering, category filters and form interaction

## Run the project
1. Download and extract the ZIP file.
2. Open the `restaurant_frontend` folder.
3. Double-click `index.html`, or open the folder in Visual Studio Code and use the Live Server extension.

No build tools or package installation are required.

## Customization
Edit the `dishes` array in `script.js` to change dish names, categories, prices, descriptions and image URLs. Update the restaurant name and contact details in `index.html`.

## Note
This is a frontend demonstration. The contact form does not send data to a server, and online ordering/payment is not connected. Food images are loaded from Unsplash and require an internet connection.
